# Contribution Guidelines

First off, thank you for considering contributing to LuminAIR! It's people like you that make the open source community such a great place to learn, inspire, and create.

## How Can I Contribute?

There are many ways to contribute to this project:

- **Reporting Bugs**: Found a bug? Open an issue and describe it as clearly as possible.
- **Suggesting Features**: Have an idea to make LuminAIR better? Open an issue and explain your proposal.
- **Improving Documentation**: Notice a typo or a confusing section? Feel free to submit a PR.
- **Writing Code**: Want to implement a feature or fix a bug? Check out our open issues and start coding!

## Getting Started

1. **Fork the Repository**: Create your own copy of the project.
2. **Clone the Fork**: Download the code to your local machine.
3. **Create a Branch**: Use a descriptive name for your branch (e.g., `fix/issue-123` or `feat/new-feature`).
4. **Make Your Changes**: Implement your fixes or features.
5. **Commit Your Changes**: Use clear and concise commit messages.
6. **Push to Your Fork**: Upload your changes to GitHub.
7. **Open a Pull Request**: Submit your changes for review.

## Getting Rewarded

We value the contributions of our community. While we no longer use OnlyDust for automated rewards, we still encourage contributors to reach out to the maintainers for potential rewards or recognition for significant contributions.

Please ensure your PR is well-documented and follows our coding standards to increase the chances of acceptance and reward.

## Coding Standards

To maintain code quality, please follow these guidelines:

- **Clean Code**: Write readable, maintainable, and efficient code.
- **Testing**: Include tests for any new features or bug fixes.
- **Documentation**: Update the documentation if your changes affect how the system works.
- **Linting**: Ensure your code passes the project's linting rules.

## Communication

If you have any questions or need help, feel free to:

- Open an issue on GitHub.
- Join our community channels (if applicable).
- Reach out to the maintainers directly.

Thank you for your contribution!
